## GitHub / LinkedIn project description

Created a Tableau loan portfolio analytics project analyzing 42,535 U.S. loan records across borrower income, homeownership, loan purpose, interest rates, debt-to-income ratios, and geographic lending trends. Built 21 worksheets and five dashboards, incorporating state-level maps, borrower comparisons, calculated fields, parameter-driven Top N analysis, interactive filters, and dashboard navigation. Used visual analysis to surface differences in income, loan size, interest rates, and monthly installment patterns across segments.

## Resume bullets
